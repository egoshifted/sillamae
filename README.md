# Sillamäe · 3D Atlas

An interactive 3D model of Sillamäe, Estonia. The town model is being progressively refined against reference imagery; detail varies between buildings.

Search for an address, drag to move, scroll to zoom, and use the rotation buttons to view another side. Adjust sunlight, textures, shadows and rendering quality with the on-screen controls.

## Publish with GitHub Pages

Upload the contents of this folder (including the vendor folder and .nojekyll) to the repository root. Do not upload the ZIP itself. In Settings → Pages, choose Deploy from a branch, main, and /(root), then Save.

The site uses static files and relative URLs, so it works under a repository subdirectory. It needs a modern browser supporting WebGL and DecompressionStream. To preview locally, serve this folder over HTTP; opening index.html directly from disk is not supported.
